# Function Documentation

## Triangle Functions (triangle.py)

### area(a, h)
Calculates the area of a triangle using base and height.

**Parameters:**
- `a` (float) - base length
- `h` (float) - height

**Returns:**
- float - area of the triangle

**Example:**
```python
result = area(8, 4)
print(result)
```
## Rectangle Functions (rectangle.py)

### area(a, b)
Calculates the area of a rectangle using length and width.

**Parameters:**
- `a` (float) - length
- `b` (float) - width

**Returns:**
- float - area of the rectangle

**Example:**
```python
result = area(10, 5)
print(result)
```
